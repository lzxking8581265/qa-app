# 项目简介

## 项目概述
基于Spring Boot + Vue3 + MySQL的完整Web应用，用于记录和展示API调用信息。

## 核心需求
1. **技术栈**：
   - 后端：Spring Boot (Java)
   - 前端：Vue3
   - 数据库：MySQL
   - 构建工具：Maven (后端)
   - 容器化：Docker + Docker Compose

2. **功能需求**：
   - Basic Auth认证
   - POST/GET接口用于接收和存储调用数据
   - 数据存储：body、header、URL、调用时间
   - 前端展示调用信息
   - 登录验证页面
   - 用户管理功能
   - 默认用户：admin/admin

3. **接口规范**：
   - RESTful API设计
   - Basic Auth认证
   - 数据记录接口
   - 数据查询接口

## 项目目标
创建一个完整的API调用记录系统，包含前后端分离架构、用户认证、数据存储和展示功能。
